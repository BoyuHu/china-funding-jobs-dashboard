# 国内大额融资与招聘岗位面板

一个可筛选的静态 HTML 面板，整理近一年国内单笔融资 5000 万元以上的公开披露事件，并汇总已核验的招聘岗位与申请入口。

## 在线访问

启用 GitHub Pages 后，可通过仓库的 Pages 地址访问。

## 功能

- 按城市、行业、融资轮次、金额区间和披露日期筛选融资事件
- 在“招聘岗位”标签中按工种、城市、公司和岗位关键词筛选
- 每条融资记录与招聘信息均保留公开资料来源链接
- 对尚未找到可靠招聘入口的公司明确标为待核验

## 文件

- `index.html`：可直接访问的静态面板
- `financing_over_50m.csv`：融资公开信息数据
- `jobs_data.json`：已核验招聘岗位数据
- `build_financing_dashboard.py`：生成面板的脚本

## 数据说明

数据用于线索发现和初步筛选，不替代投资、法律或求职尽调。招聘状态可能随时变化，申请前请再次检查对应公司或招聘平台页面。

## 本地更新

```bash
python3 build_financing_dashboard.py
cp 融资公司筛选面板.html index.html
```
